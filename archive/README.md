# archive

v1. Kept because a press kit is also a record, and because the 0.15 store
listings were built from it.

**None of this is the current identity.** The screenshots are Comfortaa, yellow
chrome and cards on a grey ground, and they are shots of v1's Ionic app. If you
are making something, [`../brand/`](../brand/) is where to look; nothing in here
should be copied out of.

The one thing that carries over is the mark itself, which did not change between
v1 and v3 — `app-resources/icon-only.png` here and `../brand/icon/default.png`
are the same drawing. What v3 replaced is the type and the UI around it.

| Path | What |
| ---- | ---- |
| `0.1.x/`, `0.3.x/` | store screenshots, iOS and Android, January 2024 |
| `app-resources/` | v1's icon and its 3600² splash; `v0.6/` is the same set one version earlier |
| `assets/icons/` | v1's PWA icon set, webp — note the `s`; the favicons are current and live at `../brand/favicon/` |
| `assets/image/badges/`, `assets/rounded/` | the v1 badge art — badges are not in 2.x's first release |
| `assets/image/how-it-works-*.png` | the three explainer images from the v1 site |
| `assets/logo-horizontal.png` | the Comfortaa wordmark. Superseded by `../brand/logo/lockup-horizontal.svg`, and explicitly not to be used |
| `marketing/` | 0.3.x promo images, the featured graphics and the preview gif |
| `video/`, `animations/` | the 2024 brand film and the projects behind it — the mark holds, but the type and the UI in it are v1's |
| `copilot/` | the AI Language Copilot deck and the Discord instruction cards |

`animations/` carries the After Effects and Premiere projects. Most of its
weight is Premiere's own audio preview cache (`.cfa`, `.pek`) — regenerable, and
kept only because it came in with the project.

Nothing in here gets overwritten. Adding is fine; replacing a shipped file is
not.
